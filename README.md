
# Campus Lost & Found Portal

> *Lost Something? Found Something? Let's Help It Find Its Way Back!*

## About the Project

Campus Lost & Found Portal is a full-stack web application designed to help students report and recover lost items within a college campus.

Students frequently lose personal belongings such as ID cards, water bottles, notebooks, bags, keys, chargers, earphones, and other important items. In many cases, there is no organized system to report these lost items or check whether someone has found them.

This platform provides a centralized and easy-to-use solution where students can report lost items, post found items, search through available reports, and help return belongings to their rightful owners.

## Project Objective

The main objective of this project is to create a centralized digital platform for college campuses where students can easily report and search for lost and found items.

The system aims to reduce the chances of permanently losing valuable belongings and encourage students to help each other by creating a connected campus community.

## Installation and Setup

### 1. Clone the Repository

bash
git clone YOUR_REPOSITORY_URL


### 2. Move into the Project Folder

bash
cd campus-lost-found


### 3. Install Frontend Dependencies

bash
cd client
npm install
npm run dev


### 4. Install Backend Dependencies

Open another terminal:

bash
cd server
npm install
npm run dev
